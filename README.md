
### Инструкция по запуску

#### 1. Установка зависимостей
Из корня проекта выполните:
```powershell
pip install -r requirements.txt
```

#### 2. Скачивание датасета
Если папки `data/dentex` еще нет, скачайте разметку:
```powershell
python scripts\download_dentex.py
```

#### 3. Генерация масок для обучения
Нейросеть учится искать зубы по пикселям. Скрипт превращает рамки (bbox) в маски. Зубы сужаются, чтобы между ними оставались черные зазоры (иначе сеть сольет их в один блок).
```powershell
python scripts\prepare_teeth_masks.py
```

#### 4. Обучение сети
Запуск обучения (веса сохраняются после каждой эпохи):
```powershell
python scripts\train_my_net.py
```
*На CPU одна эпоха занимает около 30–37 минут. Для первого результата достаточно подождать 4–10 эпох.*

#### 5. Проверка результата (Инференс)
Когда модель обучится (например, после 4-й эпохи), запустите скрипт проверки. Он возьмет тестовый снимок, прогонит через сеть и нарисует рамки.
```powershell
python check.py
```
Результат сохранится в файл **`result.jpg`**. Откройте его, чтобы убедиться, что сеть нашла зубы и правильно расставила номера.

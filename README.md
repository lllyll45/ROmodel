

#### 1. Установка зависимостей
Из корня проекта выполните:
```powershell
pip install -r requirements.txt
```

#### 2. Скачивание датасета
Скачиваем разметку DENTEX (часть `enumeration`, где размечен каждый зуб). 
```powershell
python scripts\download_dentex.py
```
*(Скрипт создаст папку `data/dentex` с картинками и `.txt` файлами разметки).*

#### 3. Генерация масок для обучения
Наша нейросеть (сегментатор) учится искать зубы по пикселям. Скрипт превращает рамки (bbox) в маски. Зубы сужаются (эллипсы), чтобы между ними оставались черные зазоры. Это нужно, чтобы сеть не сливала все зубы в один сплошной блок, а видела каждый зуб отдельно.
```powershell
python scripts\prepare_teeth_masks.py
```
*(Результат появится в `data/teeth_masks/`).*

#### 4. Обучение сети
У вас есть два варианта запуска:

**Вариант А: Обычное обучение (одна модель)**
Запускает обучение с базовыми параметрами (lr=1e-4, 30 эпох).
```powershell
python scripts\train_my_net.py
```
*Веса сохраняются после каждой эпохи в `best_model/my_tooth_net_default_run.pth`.*

**Вариант Б: Перебор гиперпараметров (Sweep)**
Запускает 5 разных вариантов (с разным `learning rate` и размером картинки) по очереди, чтобы найти лучшую модель.
```powershell
python scripts\sweep_my_net.py
```
*Результаты перебора сохранятся в `weights/candidates/report.md`.*


#### 5. Проверка результата (Инференс)
Когда модель обучится, запустите скрипт проверки. Он возьмет тестовый снимок, прогонит через вашу сеть и нарисует зеленые рамки с номерами зубов (по системе FDI).
```powershell
python check.py
```
**⚠️ Важно:** перед запуском откройте `check.py` и убедитесь, что в строке `weights_path = ...` указан путь к реально существующему файлу весов (например, `best_model/my_tooth_net_default_run.pth` или победитель из sweep).

Результат сохранится в файл **`result.jpg`** в корне проекта. Откройте его, чтобы убедиться, что сеть нашла зубы и правильно расставила номера.
